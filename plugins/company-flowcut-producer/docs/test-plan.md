# 测试计划

## 测试层级

| 层级 | 目标 | 是否产生费用 |
|---|---|---|
| 静态校验 | 插件、技能、JSON、依赖去耦与秘密扫描 | 否 |
| SQLite 单元测试 | 初始化、显式旧库迁移、严格只读查询、持久化、状态/阶段、审批、成本和链接 | 否 |
| NAS 只读集成 | 中文路径、精确产品读取、产品同目录媒体、哈希、品牌/声明审核、断网/无权限行为和零回写 | 否 |
| 素材到脚本匹配 | 分类建议、审核硬闸门、产品范围、标签/用途/时长匹配、事实引用、哈希和 ChatCut 交接清单 | 否 |
| 模板与批量计划 | 只选批准模板、请求维度匹配、批准台词渲染、变体轮换、确定性选材、逐输出哈希和整批交接闸门 | 否 |
| 本机数据隔离 | 拒绝网络任务库/工作目录、拒绝源目录重叠、预检不创建目录 | 否 |
| ChatCut 只读冒烟 | 项目、时间线和授权可见性 | 否 |
| ChatCut 编辑回归 | 可逆编辑、时间线复制、字幕、预览和导出前闸门 | 仅明确授权后 |

## 两天流程回归

`templates/test-cases/two-day-video-flow.json` 包含 8 个场景：需求补全、45 秒基线、精确 TTS 授权、套餐阻塞回退、动态重混、转场修复、25 镜头故事版和 A/B/C 受控版本。

每个场景验证产品来源、精确授权、旧版本保留、预期 ChatCut 动作、任务状态、费用影响和导出条件。

## 发布门槛

- 官方插件和技能校验器通过。
- 所有离线单元测试通过。
- NAS 只读预检及至少一个真实产品查询通过；产品和素材根无写入。
- SQLite 和工作目录只在本机，网络路径和源目录重叠配置均被拒绝。
- `task_store.py read/list` 前后数据库 SHA-256 和修改时间不变；旧库查询要求先显式 `init`。
- `prepare-product` 能发现精确产品目录媒体，把未获批准的可见品牌和内嵌声明标记为发布阻塞，并支持显式确认“未观察到品牌/声明”。
- 分类只生成元数据并保持源目录零写入；路径建议不能直接成为批准分类。
- 脚本匹配只选择产品范围、分类、标签、用途、媒体类型、时长、授权、品牌/声明、质量和哈希全部合格的素材。
- 未匹配镜头、未批准事实、素材哈希变化或重复素材均使 `ready_for_chatcut=false`，不得产生正式 ChatCut 导入清单。
- `draft`/`disabled` 模板不得自动选择；模板、平台、画幅、语言、时长、标签和数量必须匹配，模板文件 SHA-256 必须进入计划。
- 相同批量输入必须得到相同 `batch_id` 与选择清单；不同 `selection_seed` 可在同分合格素材间确定性轮换。
- 任一输出缺少批准台词、事实引用或合格素材时，整批 `chatcut_batch_handoff.ready=false`，不得把部分候选 outputs 当作正式交接。
- SQLite 冒烟能创建任务、迁移状态、记录审批/成本/链接并重新读取。
- ChatCut 只读冒烟不产生写入、导出或积分。
- 经用户授权的精确脚本剪辑在独立副本完成；只提交目标语音轨，字幕同步，画面轨总时长和删词点前后实际合成帧通过检查，原项目保持不变。
- 仓库中没有 SQLite、真实媒体、凭据、缓存或旧架构依赖。

真实部门试用再要求至少 3 个低风险项目完成“创建任务 → 编辑 → 人工闸门 → 质检 → 导出 → 会话恢复”闭环。
