## 真实试用门槛

1. 部门确认 `COMPANY_VIDEO_ASSET_ROOTS` 和 `COMPANY_VIDEO_OUTPUT_ROOT`。
2. 选定 3 个低风险任务，每个任务指定一位当前负责人。
3. 完成创建、编辑、人工闸门、质检、导出和会话恢复闭环。
4. 记录需求到首版时间、返工数、输出数量、积分/成本和恢复成功率。
